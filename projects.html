GESTEK — Plataforma de eventos de marca blanca

Plataforma de marca blanca para organizar eventos de punta a punta: página pública por organizador, boletas con QR firmado (JWT), control de puerta con reingreso y motivos de rechazo, prellenado del registro por cédula, impresión de escarapelas, carné digital, equipos con roles, pagos con Mercado Pago y registro embebible por iframe. Con ella se operó FESTECH Ibagué 2026 para la Alcaldía de Ibagué: 4.485 boletas y 3.334 ingresos en tres días, con picos de 67 ingresos en 5 minutos por una sola puerta. Un conector OAuth2 (PKCE) + MCP permite operarla desde un asistente de IA, y la respaldan más de 1.800 pruebas automatizadas.

Arquitectura: SPA React 18 + Vite (PWA) → API Express (Node 20) en cPanel → PostgreSQL en Supabase (Auth, Storage, Realtime, RLS). Build en GitHub Actions publicado a una rama deploy. Antes: Vercel + Render (hasta sep. 2026). Salida de Supabase a una base propia en curso.

Herramientas React 18 · Vite Express 5 Supabase PostgreSQL cPanel GitHub Actions Sentry MCP · OAuth2 Mercado Pago Turnstile Playwright

Producción · Cliente real

Consultorio Estético — Dra. Julieth Vanessa Medina

Plataforma para un consultorio de medicina estética en Ibagué: sitio público bilingüe (es/en), catálogo de procedimientos, agendamiento en línea, cuentas con roles, consentimiento informado con firma electrónica guardado en almacenamiento privado, panel administrativo con analítica de ingresos y un copiloto de IA que edita el contenido por chat o voz. Auditoría de seguridad con 4 fallos críticos corregidos. En integración: servidor MCP con OAuth y confirmación humana, CSP con CI y la autorización de datos de salud de la Ley 1581.

Arquitectura: Next.js 16 en Vercel → API Express en Railway → PostgreSQL 18 en Neon con SQL directo (sin SDK de proveedor) + archivos en Cloudflare R2. Auth propia: JWT en memoria, refresh rotativo en cookie httpOnly, argon2id y Google OAuth. Antes: Supabase (base, auth y storage) hasta sep. 2026.

DevUP — Centro de mando para equipos de software

Espacio de trabajo para equipos de desarrollo: canales, voz y video cifrados de extremo a extremo (malla WebRTC), tareas, ventas, bóveda de credenciales y un servidor MCP para que agentes de IA trabajen directamente sobre el tablero. Ardy-IA — Tutor de idiomas con IA

Tutor conversacional para practicar español, inglés y francés: corrige dentro de la conversación, recuerda la sesión, busca en la web para responder con contexto y acepta voz como entrada. La respuesta se lee en voz alta desde el navegador.

Wallnut — Campus digital y economía de puntos

Plataforma móvil para una institución universitaria que digitaliza las actividades del campus (charlas, debates, laboratorios, eventos de la comunidad) y plantea una nueva economía basada en puntos positivos: quien participa los gana, los acumula en su billetera y compite en un ranking. Incluye registro de asistencia por QR, billetera con historial y el asistente Ardy.

Arquitectura: app Expo / React Native con Expo Router (Android, iOS y web) → API Express. Cada movimiento de puntos se registra en un libro encadenado por hash (blockchain simulada) para que el historial no se pueda alterar sin que se note.
