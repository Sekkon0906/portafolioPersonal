GESTEK Event OS — Gestión de eventos con IA

SaaS marca blanca end-to-end para eventos: creación con editor visual y 8 plantillas, boletería con QR firmado (JWT) y códigos de respaldo, check-in, pagos MercadoPago directos al organizador, equipos con roles, chat por canales, tareas Kanban, agenda, fidelidad con puntos y analítica de conversión. API REST y webhooks con HMAC.

GESTEK Mail — Microservicio de correo

Servicio independiente que renderiza y envía las plantillas de correo diseñadas dentro de GESTEK. El backend delega vía clave compartida (x-gestek-key) y el servicio resuelve plantilla + entrega SMTP. Campañas segmentadas por equipo o tipo de boleta, healthcheck /healthz y diagnóstico SMTP para evitar bucles de reinicio en Render cuando el proveedor de correo falla.
